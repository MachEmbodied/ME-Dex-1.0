# Third-party components

The WAN implementation retains its Alibaba Wan copyright notices. Its flow-matching scheduler includes code derived from Hugging Face Diffusers, as identified in the source.

The frozen tactile encoder is extracted from the supplied V4-Uni source snapshot; its license is preserved at `tactile_encoder/LICENSE`.

DexJoCo action conversion, interpolation helpers and task configuration are adapted from the supplied DexJoCo integration. Its MIT license is preserved at `DEXJOCO_LICENSE`. Simulator code and assets are installed separately.

Source identities and migration details are documented in `../../docs/dexjoco_source_manifest.json` and `../../docs/dexjoco_migration.md`.
